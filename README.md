# Kardia Health Assistant 🏥

**Plataforma clínica avanzada para la gestión de protocolos, medicación y guías cardiológicas.**

Kardia es la herramienta definitiva para profesionales de la salud, diseñada para centralizar información crítica y herramientas de cálculo cardiológico en un entorno móvil, eficiente y siempre disponible.

## 🚀 Características Principales

*   **Protocolos Clínicos**: Acceso rápido a guías de actuación cardiológica.
*   **Gestión de Medicación**: Esquemas terapéuticos detallados y actualizados.
*   **Cálculo Cardiológico**: Herramientas integradas para estratificación de riesgo.
*   **Offline First**: Toda la información disponible sin necesidad de conexión a internet.
