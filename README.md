# Kardia Health Assistant

Plataforma médica para centralizar protocolos clínicos, esquemas de medicación y guías de morbimortalidad cardiológica.

## 🚀 Descripción
Kardia es una aplicación móvil desarrollada con **React Native (Expo)** diseñada para facilitar a los profesionales de la salud el acceso rápido a guías clínicas, protocolos de medicación y herramientas de cálculo cardiológico.

## 🛠️ Tech Stack
- **Frontend**: React Native, Expo, TypeScript
- **Backend/Database**: Supabase (PostgreSQL), Edge Functions
- **Despliegue**: EAS (Expo Application Services)
